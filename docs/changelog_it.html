Note di versione

1.9.2

  • Elenchi di scelta più belli con simboli, colori e segno di spunta, adatti al tema chiaro e scuro – ad es. l'attività nell'importazione di più file GPX, il menu delle foto e „Cime vicine“ (Android).
  • Note di versione sempre consultabili: Impostazioni → Note di versione.
  • Sicurezza: i file GPX con DTD o entità vengono rifiutati. I veri file GPX non li contengono mai, file manipolati potrebbero bloccare l'app.
  • Sicurezza: gli aggiornamenti vengono scaricati solo dalle release del repository GitHub egazzz/bergtagebuch (Android).

1.9.1

  • Tema scuro: lo sfondo della schermata iniziale era chiaro. Barra del titolo, barra di stato e finestre di sistema ora seguono anch'esse il tema (Android).

1.9

  • Tema scuro: automatico secondo l'impostazione di sistema, oppure fisso Chiaro o Scuro in Impostazioni → Tema.

1.8.1

  • I backup si possono cifrare con una password (AES-256).
  • Ricerca automatica delle cime disattivabile, nuova sezione d'aiuto „Privacy“.
  • Web app: i backup ripristinati vengono controllati, protezione aggiuntiva con una Content Security Policy. Corretto lo spillo nella scelta della posizione.

1.8

  • Nuova pagina Impostazioni: carattere (tra cui Atkinson Hyperlegible per una migliore leggibilità), dimensione di testo e app dal 100 al 150 %.
  • Le sezioni facoltative del modulo si possono chiudere.
  • Lingua, controllo aggiornamenti all'avvio e promemoria backup in un unico posto.

1.7 e precedenti

  • Diario delle escursioni con attività (anche proprie), scale di difficoltà secondo AVS e scale internazionali, foto con zoom, importazione GPX (singola e multipla), dislivello preciso, riconoscimento delle cime e cime vicine.
  • Mappa con molti tipi di mappa (incl. ortofoto e mappa di base Alto Adige) e filtri colore.
  • Statistiche con confronto con l'anno precedente, classifica delle cime e 24 traguardi.
  • Backup, rapporto diagnostico, aggiornamenti tramite GitHub con controllo a ogni avvio, aiuto in tedesco, italiano e inglese.
  • Web app per iPhone, iPad e computer su egazzz.github.io/bergtagebuch.
