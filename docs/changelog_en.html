Changelog

1.9.2

  • Nicer selection lists with icons, colours and check marks that match the light and dark theme – e.g. the activity when importing several GPX files, the photo menu and "Nearby summits" (Android).
  • Read the changelog at any time: Settings → Changelog.
  • Security: GPX files containing a DTD or entities are rejected. Real GPX files never contain them; crafted files could freeze the app.
  • Security: updates are only downloaded from the releases of the GitHub repository egazzz/bergtagebuch (Android).

1.9.1

  • Dark mode: the home screen background was light. Title bar, status bar and system dialogs now also follow the theme (Android).

1.9

  • Dark mode: automatic according to the system setting, or always Light or Dark under Settings → Theme.

1.8.1

  • Backups can be encrypted with a password (AES-256).
  • Automatic summit lookup can be switched off; new help section "Privacy".
  • Web app: restored backups are validated, extra protection through a Content Security Policy. Fixed the pin when picking a position.

1.8

  • New Settings page: font (including Atkinson Hyperlegible for better readability), text and app size from 100 to 150 %.
  • Optional sections of the tour form can be collapsed.
  • Language, update check at start and backup reminder in one place.

1.7 and earlier

  • Tour diary with activities (including your own), difficulty scales following the AVS and international scales, photos with zoom, GPX import (single and bulk), accurate elevation gain, summit detection and nearby summits.
  • Map with many map types (including South Tyrol orthophoto and base map) and colour filters.
  • Statistics with previous-year comparison, summit ranking and 24 badges.
  • Backup, diagnostic report, updates via GitHub with a check at every start, help in German, Italian and English.
  • Web app for iPhone, iPad and computers at egazzz.github.io/bergtagebuch.
